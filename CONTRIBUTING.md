# Contribuir

Este proyecto busca ser una guía práctica para usuarios y desarrolladores de IA.

Preferimos contribuciones que:

- expliquen el riesgo en lenguaje claro;
- incluyan una mitigación concreta;
- distingan entre modelo, contexto y capacidades;
- aporten ejemplos reproducibles y seguros;
- indiquen fuentes primarias cuando sea posible.

No aceptamos payloads diseñados para comprometer sistemas reales ni credenciales reales.
