# Checklist: antes de conectar un MCP

1. ¿Qué recursos puede leer?
2. ¿Qué tools expone?
3. ¿Qué tools escriben o borran?
4. ¿Puede ejecutar código?
5. ¿Puede acceder a secretos?
6. ¿Puede realizar requests externas?
7. ¿Procesará contenido no confiable?
8. ¿Puede aparecer la lethal trifecta?
9. ¿Puedo separar read/write?
10. ¿Puedo exigir aprobación humana para acciones sensibles?

### Regla

> Si el agente no necesita una capacidad, no se la des.
