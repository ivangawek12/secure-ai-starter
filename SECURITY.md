# Política de seguridad

Este repositorio estudia seguridad de sistemas de IA, agentes, MCP, RAG y skills.

No se deben subir secretos, credenciales, datos personales ni material privado.

Las demostraciones de ataques deben mantenerse en entornos controlados y con fines educativos.

Si encontrás una vulnerabilidad en código del repositorio, abrí un issue sin incluir credenciales ni datos sensibles. Para vulnerabilidades que permitan comprometer infraestructura real, contactá al mantenedor antes de publicar detalles explotables.
