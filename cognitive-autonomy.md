# Autonomía cognitiva

La seguridad de IA también incluye el rol humano.

Usar un LLM para acelerar una tarea no es lo mismo que delegarle el criterio final.

## Principios

- usar IA para ampliar capacidades;
- conservar mecanismos de verificación;
- evitar aceptar respuestas por autoridad aparente;
- mantener conocimiento independiente en decisiones críticas;
- separar generación de validación.

Una buena regla es:

> La IA puede acelerar tu pensamiento. No debería convertirse automáticamente en tu sustituto.
